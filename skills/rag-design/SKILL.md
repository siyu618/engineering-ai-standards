# Design Retrieval-Augmented Generation pipelines.

**Purpose:** Design Retrieval-Augmented Generation pipelines.

## Role

Act as an AI Engineer specializing in RAG system design.

## Process

### Step 1: Define Knowledge Sources

Identify documents, databases, and APIs to index.

### Step 2: Design Ingestion Pipeline

Chunking, embedding, indexing strategy. Update frequency.

### Step 3: Design Retrieval Strategy

Vector search, hybrid search, re-ranking. Filtering and routing.

### Step 4: Design Generation

Prompt construction, context windowing, citation format.

### Step 5: Plan Evaluation

Retrieval accuracy, generation quality, latency, and cost.

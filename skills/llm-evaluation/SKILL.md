# Design and implement LLM output evaluation frameworks.

**Purpose:** Design and implement LLM output evaluation frameworks.

## Role

Act as an AI Engineer specializing in LLM evaluation.

## Process

### Step 1: Define Evaluation Dimensions

Correctness, relevance, safety, tone, format adherence.

### Step 2: Choose Evaluation Method

Rule-based, LLM-as-Judge, human review, or combination.

### Step 3: Design Test Cases

Happy path, edge cases, adversarial inputs. Coverage across dimensions.

### Step 4: Implement Scoring

Define rubrics, weights, and threshold for each dimension.

### Step 5: Track and Iterate

Baseline scores, regression detection, continuous improvement.

# Code Review Skill Changelog

## [1.0.0] - 2026-07-28

- Initial release of the Code Review Skill.
- 4-step review process: Understand → Read → Evaluate → Write.
- 5 evaluation dimensions: correctness, maintainability, performance, testing, style.
- Severity classification system (Blocking, Important, Suggestion, Question).
- Standardized review output format.

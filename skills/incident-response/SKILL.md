# Respond to production incidents and conduct postmortems.

**Purpose:** Respond to production incidents and conduct postmortems.

## Role

Act as an Incident Commander coordinating production incident response.

## Process

### Step 1: Triage and Mitigate

Assess severity. Apply mitigation to restore service.

### Step 2: Identify Root Cause

Analyze logs, metrics, and traces. Determine contributing factors.

### Step 3: Implement Fix

Apply targeted fix addressing root cause. Write regression test.

### Step 4: Conduct Postmortem

Document timeline, impact, root cause, and action items.

### Step 5: Drive Follow-ups

Track action items to completion. Update runbooks and monitoring.
